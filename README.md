# Три уровня тревоги

Лендинг обновлённой программы Павла Федоренко для выпускников Института
когнитивно-поведенческой психотерапии.

## Структура

| Файл | Что это |
|---|---|
| `source/page.html` | Исходник страницы: разметка, стили и скрипты в одном файле. Правим только его. |
| `index.html` | Собранная страница для публикации. Генерируется из исходника, руками не редактируется. |
| `build.js` | Сборка: оборачивает исходник в полноценный HTML-документ. |
| `server.js` | Локальный статический сервер для просмотра. |

Изображения (логотип, портреты, кадр-обложка видео) встроены в страницу как
data-URI, поэтому `index.html` самодостаточен и не тянет внешних файлов.

## Как работать

```bash
node build.js     # пересобрать index.html после правок в source/page.html
node server.js    # открыть http://localhost:8123
```

## Видео

Видеообращение Павла подключается тегом `<video>` с файлом `pavel.mp4`.
Сам файл в репозиторий не входит: десять минут в 720p весят около 540 МБ,
это превышает лимиты GitHub и слишком тяжело для загрузки в браузере.

Для публичного сайта ролик нужно разместить на видеохостинге
(Kinescope, VK Видео, YouTube) и заменить тег `<video>` на встраиваемый плеер.
Кадр-обложка уже встроен в страницу и показывается до запуска.

## Что нужно подставить перед запуском

Кнопки призыва к действию сейчас ведут на якоря внутри страницы. Ссылки на
оплату помечены комментарием в `source/page.html`.
